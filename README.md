# Workforce Intelligence: Employee Attrition & Retention Analysis

## 1. Project Overview

This project analyses a simulated workforce of 600 employees across six departments and four locations.

The objective is to identify employee attrition patterns, examine workforce distribution, analyse compensation and explore factors associated with employee turnover.

## 2. Tools Used

- Microsoft Excel
- SQL (SQLite)
- GitHub

## 3. Dataset Description

The dataset contains 600 simulated employee records with the following fields:

- Employee ID
- Employee name
- Department
- Monthly salary
- Employment status
- Years of service
- Hire date
- Termination date
- Location
- Job level
- Performance rating
- Overtime hours

## 4. Business Questions

The analysis investigates the following business questions:

- What is the overall workforce distribution?
- Which departments have the highest employee turnover?
- Does length of service relate to employee attrition?
- Is overtime associated with higher employee turnover?
- What workforce patterns could help inform employee retention strategies?

## 5. SQL Analysis

SQL was used to perform:

- Workforce data validation
- Employee headcount analysis
- Departmental turnover calculations
- Tenure-based attrition analysis
- Overtime and employee turnover comparisons

## 6. Excel Analysis

The Excel component includes:

- Employee headcount analysis by department
- Employee attrition and turnover calculations
- Average monthly salary analysis
- PivotTables and PivotCharts
- HR dashboard with key performance indicators

The original Excel dashboard uses an initial 12-employee sample. It is being aligned with the expanded 600-employee dataset.

## 7. Key Findings

Initial SQL analysis identified:

- Sales recorded the highest departmental turnover rate at 50%.
- Operations recorded a turnover rate of 20%.
- The high-overtime category recorded 20% turnover, compared with 5% in the low-overtime category.
- Employees with five or more years of service recorded lower turnover than the two-to-four-year group.

These are preliminary findings from simulated data and should not be interpreted as evidence of real-world causation.

## 8. Project Limitations

- The dataset is simulated and does not represent a real organisation.
- The findings are dependent on the assumptions used to generate the data.
- Observed relationships do not establish causation.
- Further validation and analysis are required before drawing broader business conclusions.
